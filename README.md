🎉 We’re Back!

Bourbon is the modern continuation of the Whisky experience.

It’s the same great Whisky you know and love, refreshed and updated for 2026 with an actively maintained Wine runtime, improved compatibility, bug fixes, and ongoing development.

We’re just getting started, and we’re not going anywhere.

Features

* Native SwiftUI interface
* Modern Wine runtime
* Automatic runtime installation
* Bottle management
* Winetricks integration
* DXVK & Vulkan support
* Apple Silicon optimized
* Active development

⸻

System Requirements

* Apple Silicon (M-series)
* macOS Sonoma 14 or newer

⸻

Installation

Homebrew

brew tap Unblockerfire/bourbon
brew install --cask bourbon

Or download the latest release from the Releases page.
